BALCON is not bundled with this project.

Download the complete official Balabolka Console Utility package from:
https://www.cross-plus-a.com/en/bconsole.htm

Extract the complete package into this directory. Keep balcon.exe together with
all DLL files supplied in the archive. The API invokes balcon.exe with this
folder as its working directory so its companion libraries can be found.

Expected path after publishing:
  release\tools\balcon\balcon.exe

Alternatively set TTS7_BALCON_API_BALCON to the absolute path of balcon.exe.
The package is freeware distributed by Cross+A; consult its author for the
applicable license and redistribution terms. This repository does not include
BALCON or its DLLs.
